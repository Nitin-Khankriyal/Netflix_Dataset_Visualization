# 🎬 Netflix Dataset Visualization

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) and data visualization of the Netflix Titles dataset using Python. The goal is to uncover trends and patterns in Netflix's content library by analyzing content types, ratings, release years, countries, movie durations, and TV show seasons.

Through data cleaning, transformation, and visualization, meaningful insights were extracted from the dataset to better understand Netflix's content distribution.

---

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 📂 Dataset Information

The dataset contains information about Netflix content, including:

- Title
- Type (Movie / TV Show)
- Country
- Release Year
- Rating
- Duration
- Genre
- Date Added

---

## 🔍 Analysis Performed

### 1. Content Type Analysis
- Distribution of Movies and TV Shows
- Comparison between Indian and International content

### 2. Country Analysis
- Top countries contributing content to Netflix
- Country-wise content distribution

### 3. Rating Analysis
- Distribution of content ratings
- Comparison of ratings for Indian and International content

### 4. Release Year Analysis
- Content release trends over time
- Growth of Netflix's content library

### 5. Movie Duration Analysis
- Distribution of movie runtimes
- Most common duration ranges

### 6. TV Show Season Analysis
- Distribution of TV show seasons
- Season frequency analysis

---

## 📊 Key Insights

- Movies make up the majority of Netflix's content catalog.
- Netflix content production has increased significantly over the years.
- A few countries contribute a large percentage of the available content.
- Most movies fall within a standard runtime range.
- TV Shows typically have fewer seasons, while long-running series are relatively rare.
- Content ratings vary across regions and content types.
