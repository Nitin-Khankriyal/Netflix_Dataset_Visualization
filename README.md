# Netflix Dataset Visualization

## Overview
Performed Exploratory Data Analysis (EDA) on the Netflix Titles dataset using Python to identify content trends, distribution patterns, and insights through data visualization.

## Tools Used
- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Movies vs TV Shows distribution
- Top content-producing countries
- Content rating analysis
- Release year trends
- Movie duration distribution
- TV Show season distribution

## Key Insights
- Movies dominate Netflix's content library.
- Netflix content production increased significantly over the years.
- A small number of countries contribute most of the content.
- Most movies fall within a common runtime range.
- Most TV Shows have relatively few seasons.

## Files
- `main.ipynb` – Complete analysis and visualizations
- `netflix_titles.csv` – Dataset
